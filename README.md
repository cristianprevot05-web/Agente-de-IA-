# Agente-de-IA-
Este repositório contém o código do Agente de IA, supervisor técnico em IA com Streamlit. Ele unifica a triagem de ordens de serviço do ERP IXC à recuperação precisa de manuais e senhas via arquitetura RAG (busca semântica via FuzzyWuzzy e tabelas blindadas), usando o LM Studio com temperatura 0.0 para eliminar alucinações.
